# Portfolio Alyaa Mutiara Lathifa

Website portfolio pribadi yang dibuat sebagai tugas Slicing Website HTML/CSS/JS.

## 👩‍💻 Tentang Website

Website ini merupakan portfolio sederhana yang berisi informasi mengenai diri saya, riwayat pendidikan, kemampuan yang sedang dipelajari, serta sosial media.

Website dibuat dengan desain bernuansa biru, sederhana, dan responsive agar dapat digunakan pada berbagai ukuran layar seperti desktop, tablet, dan mobile.

## ✨ Fitur

- Responsive design
- Navigation menu
- Home / landing section
- About Me
- Riwayat pendidikan
- Skills
- Social media
- Mobile navigation menu
- Animasi saat halaman di-scroll
- Tahun pada footer otomatis menggunakan JavaScript

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- DOM (Document Object Model)

Website dibuat menggunakan **Plain CSS** tanpa menggunakan framework seperti Bootstrap atau Tailwind CSS.
